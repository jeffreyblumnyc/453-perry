# 453 Perry Road — Remodel Blueprint

Static site: moodboard, before/after comparisons, plans and location for the remodel of 453 Perry Road, Swan Lake, NY.

- `index.html` — the page
- `component.js` — page data (categories, renders, before/after pairs)
- `app.js` — moodboard filter and before/after sliders
- `images/` — renders and site photos

No build step. Deployed on Vercel as a static site (framework preset: Other).
